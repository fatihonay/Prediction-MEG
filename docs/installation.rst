Installation
============

Requirements
------------

* Python >= 3.11
* MNE-Python
* NumPy
* SciPy
* Matplotlib

Clone repository

.. code-block:: bash

    git clone https://github.com/fatihonay/Prediction-MEG.git

Create environment

.. code-block:: bash

    conda create -n prediction python=3.11

Activate

.. code-block:: bash

    conda activate prediction

Install dependencies

.. code-block:: bash

    pip install -r requirements.txt
