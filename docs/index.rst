Prediction-MEG
==============

**Prediction-MEG** is an open-source framework for studying predictive neural
representations using Magnetoencephalography (MEG).

The project provides reproducible pipelines for preprocessing,
visualization, feature extraction, decoding, and statistical analysis.

-------------------------------------------------

Scientific Motivation
---------------------

The human brain continuously predicts future sensory events.
Prediction-MEG aims to investigate these predictive mechanisms using
high-temporal-resolution MEG recordings.

Main Features
-------------

* Reproducible preprocessing
* MNE-Python compatible
* Feature extraction
* Machine learning
* Statistical analysis
* Publication-quality visualization
