# About

Prediction-MEG is a research-oriented Python framework dedicated to studying
predictive neural processing using magnetoencephalography.

## Motivation

Prediction is considered a fundamental computational principle of the brain.
This project aims to provide reproducible pipelines that enable researchers to
investigate predictive mechanisms from MEG recordings.

## Goals

- Reproducible preprocessing
- Open science
- Easy-to-use workflows
- Educational documentation
- Modern machine learning

## Vision

Prediction-MEG aims to become an open ecosystem for predictive neuroscience,
bridging computational methods and experimental MEG research.
